## Engineering Principles

| Principle | In practice |
|:---|:---|
| *Mobile-first* | Design for the smallest screen, then scale up with breakpoints |
| *Accessible by default* | Semantic elements, labels, focus states, sufficient color contrast |
| *Reusable components* | Small, single-purpose components with clear props |
| *Performance-aware* | Optimized images, lazy loading, minimal re-renders, Lighthouse checks |
| *Readable code* | Clear naming, consistent structure, small commits with meaningful messages |
